# Wordsworth — interactieve demo

Statische demo van de soevereine PII-straat: zoeken/rangschikken over pseudoniemen en sleutel-gated reveal per afdeling. **Synthetische** voorbeeldgegevens — geen echte persoonsgegevens.

Live: https://mwest2020.github.io/wordsworth-demo/

Eén self-contained `index.html` (alleen Google Fonts via CDN). De reveal draait client-side, puur ter illustratie van het mechanisme.
